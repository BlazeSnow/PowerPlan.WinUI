## Einführung

> [!TIP]
> Weitere Informationen zur App finden Sie auf der Website: <https://powerplan.blazesnow.com/de/>

Verwenden Sie PowerPlan, um schnell zwischen Windows-Energiesparplänen zu wechseln!

Die Oberfläche unterstützt sieben Sprachen: vereinfachtes Chinesisch, traditionelles Chinesisch, Englisch, Deutsch, Spanisch, Französisch und Italienisch.
