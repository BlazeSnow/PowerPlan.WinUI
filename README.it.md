## Introduzione

> [!TIP]
> Per ulteriori informazioni sull'app, visitare il sito web: <https://powerplan.blazesnow.com/it/>

Usa PowerPlan per cambiare rapidamente le combinazioni di risparmio energia di Windows!

L'interfaccia supporta sette lingue: cinese semplificato, cinese tradizionale, inglese, tedesco, spagnolo, francese e italiano.
